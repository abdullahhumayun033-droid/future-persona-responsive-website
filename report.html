Syed Abdullah Humayun - Portfolio Report

Introduction

This website showcases my professional portfolio as an architect and computer scientist in the year 2034. I specialize in merging artificial intelligence (AI) with architectural design, creating properties that are not merely structures but intelligent systems. These AI-integrated buildings adapt to their occupants, optimize energy usage, and ensure a sustainable living environment. The portfolio is designed for potential clients, collaborators, and industry professionals, highlighting my journey, key projects, future plans, and the team behind the innovations. The website is structured into five distinct pages, each offering insights into different facets of my professional life and vision.

Code References:

  • HTML Structure: The use of semantic HTML elements is prevalent across all pages, such as <header>, <nav>, <section>, and <footer>. For example, in about.html, the <section> element is used to encapsulate the main content about my background.
  • CSS for Layout: The layout is managed using CSS Grid and Flexbox. In my-works.css, Flexbox is used to create a responsive gallery display for my projects, ensuring a consistent and adaptive layout.

Inspiration

In developing this portfolio, I was inspired by the following professional sites:

  1. Bjarke Ingels Group (BIG) - What I Learned: The clean, modern design and innovative use of visuals to communicate complex ideas were key takeaways. This influenced the "Future Plans" section on future-plans.html, where visual storytelling is crucial. CSS animations (referenced in future-plans.css, particularly the .flip-card class) were used to create engaging visual effects that reflect my vision for AI in architecture.
  2. Zaha Hadid Architects - What I Learned: The bold use of animations and interactive elements to engage users inspired the interactive aspects of my site. For instance, the hover effects and expandable sections on my-works.html are implemented using CSS transitions and keyframes (@keyframes fadeInUp in my-works.css).
  3. Norman Foster Foundation - What I Learned: The site’s clear navigation and accessibility features were instrumental in guiding my design choices. The navigation across all pages (<nav> elements styled in styles.css) is consistent and user-friendly, ensuring easy access to all sections of the site.

Code References:

  • Animations: In my-works.css, the .work-item:hover effect uses CSS transitions to provide smooth visual feedback, inspired by Zaha Hadid Architects' site.
  • Navigation: The navigation bar, consistent across about.html, contact.html, and other pages, is styled in styles.css with responsive adjustments handled through media queries.

Accessibility

To make the site accessible to a broad audience, including those with different abilities, I implemented the following features:

  • Use of ALT Text for Images: All images on the site include descriptive ALT attributes, such as <img src="images/work1.webp" alt="AI-Powered Urban Planning"> in my-works.html, ensuring that screen readers can convey the content to visually impaired users.
  • Keyboard Navigation: The site can be fully navigated using only a keyboard, with clear focus states on interactive elements like links and buttons. This is achieved through CSS (:focus styles in team.css to enhance keyboard accessibility).
  • High Contrast and Readable Fonts: The design employs a high-contrast color scheme and readable fonts to accommodate users with visual impairments. For example, in contact.css, the contrast between background and text colors was carefully chosen (color: #000; background-color: #fff;) to ensure readability.

Code References:

  • ALT Text: Example from my-works.html <img src="images/eco-friendly.webp" alt="Eco-Friendly Earth Shelters">.
  • Focus States: In team.css, the :focus pseudo-class is applied to navigation links to ensure they are highlighted when accessed via keyboard.
  • Contrast: In contact.css, high-contrast styles are used in the contact form (input, textarea { background-color: #fff; color: #000; }).

Usability

Usability was a core consideration throughout the design and development process, addressed in the following ways:

  • Intuitive Navigation: A consistent navigation bar across all pages ensures users can easily find and access different sections of the site. The navigation bar (<nav> element) is styled in styles.css and dynamically adjusts its layout using media queries for responsiveness.
  • Responsive Design: The site is fully responsive, with CSS media queries implemented in all stylesheets (e.g., @media (max-width: 768px) in my-works.css) to ensure the layout adapts smoothly to different screen sizes.
  • Interactive Elements: Interactive features, such as hover effects and expandable sections, enhance user engagement. For instance, in future-plans.css, the .flip-card class uses 3D transforms to create a card-flipping effect that illustrates AI-driven future projects.

Code References:

  • Responsive Design: Media queries in team.css adjust the layout of team member cards to ensure they are displayed properly on smaller screens.
  • Interactive Elements: In my-works.css, the .work-item:hover rule provides visual feedback when users hover over project thumbnails.

Learning

Throughout the development of this site, I had to learn and apply new concepts in the following areas:

  • Advanced CSS Animations: I learned how to create CSS animations, such as those used in the "My Works" page (@keyframes fadeInUp in my-works.css), to create dynamic, engaging content that demonstrates AI integration in architecture.
  • JavaScript for Dynamic Content Loading: I explored JavaScript techniques for dynamic content loading, which are used in my-works.js to load additional project details without reloading the page.
  • Accessibility Best Practices: I deepened my understanding of accessibility, particularly how to make complex AI concepts understandable for users with disabilities. This included the use of ARIA roles and ensuring keyboard navigability across the site.

Code References:

  • CSS Animations: The .fadeInUp animation in my-works.css adds a smooth, upward fade-in effect to content as it enters the viewport.
  • JavaScript: In my-works.js, the dynamic content loading is handled using event listeners that load project details on demand.

Evaluation I: Successful Aspects

  • Integration of AI Concepts: The site effectively communicates how AI is integrated into architectural design, making complex ideas accessible and engaging. The "Future Plans" page (future-plans.html) is particularly successful in this, using a combination of CSS 3D transforms and JavaScript to demonstrate AI's impact on future living spaces.
  • Responsive and Interactive Design: The website is fully responsive, with interactive elements that enhance user engagement. The responsiveness is particularly evident in the media queries used across the CSS files (team.css, my-works.css), ensuring the site adapts well to various screen sizes.
  • Consistent Aesthetic: The design aesthetic is consistent across all pages, creating a professional and cohesive look. This is managed through the use of a shared stylesheet (styles.css) that standardizes colors, typography, and layout elements.

Code References:

  • AI Integration: The use of CSS 3D transforms in future-plans.css (.flip-card) demonstrates AI-driven innovations in architecture.
  • Responsive Design: The media queries in team.css ensure the team section is visually consistent across devices.

Evaluation II: Areas for Improvement

  • Advanced JavaScript Features: Although the JavaScript functions effectively, further exploration of advanced features, such as integrating AI-driven simulations, could enhance the site's interactivity. This could be implemented in future-plans.js with more sophisticated data handling and dynamic updates.
  • Expanded Content on Future Technologies: Additional content, such as case studies or detailed white papers on AI in architecture, could provide deeper insights for users. These could be integrated into the "Future Plans" section with downloadable PDFs linked from future-plans.html.
  • Additional Accessibility Features: While the site meets accessibility standards, further enhancements, such as voice navigation or more robust ARIA roles, could be implemented. This could be expanded in about.html with additional keyboard shortcuts and screen reader-specific cues.

Code References:

  • JavaScript Features: Current implementation in my-works.js is effective but could be expanded with more advanced event handling and dynamic content.
  • Accessibility: Consider expanding the use of ARIA roles in about.html to improve screen reader support.
