# Future Persona – Responsive Portfolio Website

A multi-page responsive front-end website created as the final project for **CM1040 Web Development** in the University of London BSc Computer Science programme.

The project presents a **fictional future professional persona** through an interactive portfolio-style website. Future awards, organisations, projects, team members and media appearances shown in the site are part of the coursework concept and should not be interpreted as current real-world claims.

## Features

- Multi-page responsive website
- Responsive desktop and mobile navigation
- Interactive project and media sections
- CSS animations and hover effects
- JavaScript-driven interactions
- Dynamic homepage content using Handlebars.js
- Contact form interface
- Future-plans and portfolio sections
- Design report and original wireframes

## Technologies

- HTML5
- CSS3
- JavaScript
- Handlebars.js
- Font Awesome

## Running Locally

This is a static website. You can open `index.html` directly in a browser, or run a simple local web server from the project directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

The repository is suitable for GitHub Pages deployment because the homepage is `index.html` and the project uses static HTML, CSS and JavaScript.

## Coursework Context

This repository is a cleaned portfolio version of the original CM1040 final project. IDE metadata and operating-system files have been removed, while the original project structure, report, wireframes and implementation have been retained.

Some contact, social-media and media links inside the website are prototype placeholders from the original future-persona concept.
